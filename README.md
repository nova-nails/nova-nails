# Nova Nails – Website

One-Pager für das Nagelstudio Nova Nails by Julia Tellenbach, Buochs NW. Astro 7 + Tailwind 4, statisch, Hosting Netlify.

```bash
npm install
npm run dev        # http://localhost:4324
npm run build      # dist/
npm run assets     # Logo-SVG, Favicons, OG-Bild, Porträt aus brand/ neu erzeugen
npm run pe:dev     # Bearbeiten-Modus lokal: http://localhost:4335/bearbeiten
```

- Inhalte und Schalter: `content/*.json` (Schalter in `content/site.json`, Preise nur in `content/preise.json`)
- Design-System: `docs/design-system.md`, live unter `/styleguide`
- Deployment und Konten: `docs/deployment.md`
- Bearbeiten-Modus (Julia ändert Texte, Preise, Foto unter `/bearbeiten`): `docs/bearbeiten-modus.md`, Anleitung für Julia `docs/anleitung-julia-bearbeiten.md`
- Offene Punkte Inhaberin: `docs/todo-inhaberin.md`
- Qualität: `docs/qa.md`

Gestaltung: Peter & Co Webdesign
